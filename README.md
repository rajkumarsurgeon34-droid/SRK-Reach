# 👁 SRK Reach

**Eyes on the whole internet, in your pocket.** One search box for the Web, YouTube, Reddit, GitHub, X and RSS feeds, with AI summaries and answers. An Android app by **ShazVerse Technologies**.

## What it does

| Source | Search | Paste a link |
|---|---|---|
| 🌐 Web | Free Exa search | Any page as clean text (Jina Reader) |
| ▶️ YouTube | Videos | Full **transcript** + description |
| 👽 Reddit | Posts, or `r/name` for a subreddit | Post + top comments |
| 🐙 GitHub | Repos | Repo + README, issues, pull requests |
| 𝕏 X | via web search | Post or profile (FxTwitter) |
| 📰 RSS | – | Latest posts from any feed |
| 📺 Bilibili / 💬 V2EX | – | Video info / topic + replies |

- **✨ Ask AI**: searches the chosen source, reads the top results and writes an answer with numbered sources.
- **✨ Summarise / Ask about this**: works on anything you open, e.g. a 1-hour lecture transcript.
- **🩺 Source check**: tests every source, like `agent-reach doctor`.
- AI uses **Google Gemini (free key)** or **DeepSeek**. Add your key in ⚙️ Settings. Searching and reading need no key.
- Everything runs on the phone. There's no server, and your keys stay on the device.

## Install

Every push to `main` builds the APK with GitHub Actions. Download **SRK-Reach.apk** from **Releases** and open it on your phone.
